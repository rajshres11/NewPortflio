# Shresth Raj Portfolio

A React and TanStack Start portfolio site.

## Requirements

- Node.js 22 or newer
- npm 10 or newer

## Run locally

```powershell
npm install
npm run dev
```

Vite prints the local address when the development server starts.

## Build and run in production

```powershell
npm run build
npm start
```

The production server listens on the port provided by the host (or port 3000 by default). The build uses Nitro's Node server output in `.output/`.

## Deploy

Use any Node.js host that supports a long-running server process. Set the build command to `npm run build` and the start command to `npm start`.
